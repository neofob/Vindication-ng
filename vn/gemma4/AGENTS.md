# Project Agents Reference - Vindication-ng (Vietnamese Translation)

This document serves as a reference for style and formatting standards applied to the translation of "Vindication of the Rights of Woman" in this workspace.

## Formatting Standards for Translation Files

The goal is to provide a professional, readable experience on digital monitors across all translated files (`*-vn.md`), moving away from raw text formats with artificial line breaks.

### 1. General Layout
- **Flow**: Artificial line breaks within paragraphs must be removed to allow natural wrapping on modern displays.
- **Main Title**: Always use H1 (`#`) for the main title of each file.
- **Structure**: Long documents should be broken into thematic sections using H2 (`##`) headers to improve scannability and logical flow.

### 2. Styling Guide
Specific semantic markers are used to differentiate between authorial voice, external labels, and key philosophical concepts:

| Style | Usage | Examples |
| :--- | :--- | :--- |
| **Bold** | Key philosophical anchors and core arguments | **"con người"**, **"lý trí"**, **"đức hạnh"** |
| *Italics* | Quotes, labels/phrases used by others, and footnotes | *"chiếc bình yếu hơn"*, *"Sự nhạy cảm của trái tim"* |

### 3. Book Structure & File Map
The translation follows the order of these files:
- `Sketch-vn.md`
- `Intro-vn.md`
- `Letter-vn.md`
- `ch-01-vn.md` through `ch-13-vn.md`

### 4. Specific Structure for `Intro-vn.md`
When editing the Introduction, maintain the following thematic division:
1. **LỜI GIỚI THIỆU** (Main Title)
2. *Sự sai lệch trong giáo dục phái nữ*
3. *Tác động của những tác phẩm hướng dẫn*
4. *Bản chất tự nhiên và sự hạ thấp nhân tạo*
5. *Hướng tới những đức hạnh cao quý*
6. *Tầng lớp trung lưu và sự tinh tế giả tạo*
7. *Mục tiêu: Phẩm giá và Lý trí*
8. *Về phong cách trình bày*
9. *Hệ quả của sự phù phiếm*
